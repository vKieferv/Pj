# Herramientas Papa John's

Página web de una sola pantalla con herramientas de apoyo para el turno:

- **Rótulo automático:** calcula fechas y horas de vencimiento (caja, preparado y producto) según el producto y la fecha de rotulado.
- **Descuentos:** precio final y ahorro para 10 %, 20 %, 25 %, 30 %, 40 % y 50 %.
- **Fechas:** fechas a +N días y horas a +N horas desde ahora.
- **Mural:** carga el Excel de diarización del mes (se lee solo en el navegador) y calcula metas, cumplimiento y diferencias para anotar en la pizarra.

Publicada con GitHub Pages en **https://vkieferv.github.io/Pj/**.

## Estructura

| Archivo | Contenido |
|---|---|
| `index.html` | Toda la app (HTML, CSS y JavaScript en un solo archivo, sin compilación). |
| `CHANGELOG.md` | Historial de cambios por versión. |

## Desarrollo

1. Edita `index.html` y ábrelo en el navegador para probar.
2. Registra el cambio en `CHANGELOG.md` (sección de la versión correspondiente).
3. Haz commit con un mensaje tipo [Conventional Commits](https://www.conventionalcommits.org/es/) (`feat:`, `fix:`, `style:`, `docs:`…) y sube a `main`; GitHub Pages se actualiza en uno o dos minutos.
